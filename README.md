# 心海群島

青年班會課前導覽網站，3D 互動逛島、闖關答題。

- `index.html`：首頁，兩個入口
- `liuzu.html`：曹溪群島（六祖大師法寶壇經十品，10 座島、51 站）
- `jieyi.html`：解疑群島（一貫道疑問解答，9 座主題島、54 站，含全書 121 題原文）
- `garden.js`、`garden.css`：兩座群島共用的 3D 引擎與樣式（three.js r128）
- `liuzu-data.js`、`jieyi-data.js`、`book-data.js`：各站內容、闖關題與全書原文
- `xingyou.html`：舊「行由島」連結，自動轉到曹溪群島〈行由品〉

閱讀進度、闖關紀錄只存在各自的瀏覽器裡。
